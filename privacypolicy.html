Privacy Policy

Last updated: {{LAST_UPDATED_DATE}}

This policy explains what data {{PROJECT_NAME}} accesses through Google APIs, why, and how it is handled. {{PROJECT_NAME}} is a single-operator automation pipeline, not a public service with user accounts, so this policy is written from that scope.

What this app is

{{PROJECT_NAME}} is a scheduled script that runs in GitHub Actions. It has no website login, no user-facing accounts, and no visitors other than the operator. The only "user" who authorizes it is the operator's own Google account.

What Google data it accesses

The pipeline authenticates to Google APIs using OAuth 2.0, scoped to:

  • YouTube Data API — to upload videos and set their title, description, and visibility on the operator's own YouTube channel.
  • Google Drive API (if enabled) — limited to files the app itself creates or that are explicitly shared with it, used only to read source images and store files the pipeline has already processed.

No other Google account data is requested, and the app never reads or accesses data belonging to any account other than the operator's own.

How that data is used

Data retrieved through these APIs is used solely to generate and publish the videos described on the home page. It is not analyzed, profiled, sold, rented, or used for advertising of any kind.

Google API Services User Data Policy

{{PROJECT_NAME}}'s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

What is not done with this data

  • It is not shared with third parties.
  • It is not used to train or fine-tune any model.
  • It is not used for advertising or ad targeting.
  • It is not read by anyone other than the operator.

Storage and security

OAuth client credentials and refresh tokens are stored as encrypted secrets in the project's GitHub Actions configuration. They are never committed to source control, logged, or exposed in build output. Generated videos and their source images are stored in the project's own repository or private cloud storage, not in any third-party analytics or marketing system.

Revoking access

Because authorization happens through standard Google OAuth, access can be revoked at any time from the operator's Google Account, under Security → Third-party access. Revoking access stops the pipeline from being able to authenticate on the next run.

Changes to this policy

If what this pipeline accesses or how it uses that access changes, this page will be updated and the date above revised accordingly.
